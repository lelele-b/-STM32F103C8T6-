# 串口通信协议

设备通过 USART1（PA9/PA10）与上位机通信，默认参数 **115200 bps、8 位数据位、1 位停止位、无校验**。

协议是「一问一答之外的默认主动上报」模型：设备按固定周期主动向上发送监测帧，同时随时接收上位机下发的命令。所有报文以 `\r\n` 结尾。

## 1. 数据帧

默认每秒发送一帧，单行 JSON：

```json
{"t":12345,"light":{"raw":2048,"pct":50.0,"mv":1650},"temp":{"raw":2048,"c":25.3,"mv":1650},"alarm":0,"muted":0,"th":{"temp":40.0,"light":20}}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `t` | 整数 | 设备上电后的毫秒计数，约 49.7 天回绕 |
| `light.raw` | 整数 | 光照通道 12 位 ADC 原始值，0–4095 |
| `light.pct` | 小数 | 光照强度百分比，0.0–100.0 |
| `light.mv` | 整数 | 光照通道电压，单位毫伏 |
| `temp.raw` | 整数 | 温度通道 12 位 ADC 原始值，0–4095 |
| `temp.c` | 小数 | 温度，单位摄氏度，限幅 −40.0–120.0 |
| `temp.mv` | 整数 | 温度通道电压，单位毫伏 |
| `alarm` | 整数 | 报警位掩码：`bit0` = 温度超上限，`bit1` = 光照低于下限 |
| `muted` | 整数 | 蜂鸣器是否静音，`0` 未静音，`1` 已静音 |
| `th.temp` | 小数 | 当前温度报警上限，摄氏度 |
| `th.light` | 整数 | 当前光照报警下限，百分比 |

所有小数字段固定输出一位小数，整数部分不带前导零。

## 2. 调试信息

设备输出的、以 `#` 开头的行都不是 JSON，属于调试与命令应答，上位机可直接忽略：

```
# Env Monitor 1.0 ready
# UART1 115200 8N1, send h for help
# th_temp=40.0
# ERR bad value, expect t=40 or t=40.5
```

## 3. 下行命令

命令不区分大小写，参数与命令之间用空格分隔，也可以写成 `t 40.5`。每条命令以 `\n` 或 `\r\n` 结尾。

| 命令 | 参数 | 说明 | 示例 |
| --- | --- | --- | --- |
| `h` | 无 | 打印帮助 | `h` |
| `v` | 无 | 打印版本、波特率、周期与两个阈值 | `v` |
| `r` | 无 | 立即上报一帧，`t` 字段为 0 | `r` |
| `m` | 无 | 切换蜂鸣器静音状态 | `m` |
| `t` | 摄氏度，可带一位小数 | 设置温度报警上限，限幅 −40.0–120.0 | `t 40.5` |
| `l` | 整数百分比 | 设置光照报警下限，限幅 0–100 | `l 20` |
| `p` | 整数秒 | 设置上报周期，限幅 1–60 秒 | `p 2` |

### 应答格式

| 应答 | 含义 |
| --- | --- |
| `# th_temp=40.0` | 阈值设置成功 |
| `# th_light=20` | 光照下限设置成功 |
| `# period=2000` | 上报周期设置成功，单位毫秒 |
| `# mute=1` | 静音状态已切换 |
| `# ERR bad value, ...` | 参数格式错误 |
| `# ERR unknown cmd, ...` | 未知命令 |

## 4. 报警判定

- **温度报警**：温度高于 `th.temp` 连续 3 次采样后置位；回落到 `th.temp - 2.0 ℃` 以下才清除
- **光照报警**：光照低于 `th.light` 连续 3 次采样后置位；回升到 `th.light + 5 %` 以上才清除
- 任一报警置位且未静音时，蜂鸣器导通、PA0 指示灯 5 Hz 快闪
- 静音后蜂鸣器停止，指示灯转为常亮，报警位仍然置位

回差与连续确认用于抑制阈值附近的抖动，避免蜂鸣器频繁通断。

## 5. 上位机对接建议

1. 按行读取，`strip()` 后先判断是否以 `#` 开头
2. 用 `json.loads` 解析，解析失败说明存在粘包/半包，丢弃该行即可
3. 断线重连时重新打开串口，不要依赖 `t` 字段作为绝对时间
4. 需要下发命令时，注意不要在同一时刻连续发送多条，建议间隔 100 ms
